# Grafana dashboards for MaxIO

Configure Prometheus with the [MaxIO metrics guide](../README.md), then import any of these example dashboards into Grafana:

- [Server dashboard](minio-dashboard.json)
- [Node dashboard](node/minio-node.json)
- [Bucket dashboard](bucket/minio-bucket.json)
- [Replication node dashboard](replication/minio-replication-node.json)
- [Replication cluster dashboard](replication/minio-replication-cluster.json)

These inherited dashboard JSON files are examples. Review their data source, metric names, and labels for your deployment before use.
