# Native IPFS integration

The IPFS extension is disabled by default. Set `MAXIO_IPFS_ENABLED=true` and provide the required administrator configuration to enable it. Start with [architecture](architecture.md), [configuration](configuration.md), [IPNS](ipns.md), and [security](security.md). See [examples](examples.md) for S3 clients. The implementation currently covers public files; the limitations in [architecture](architecture.md) are part of the current release boundary.
