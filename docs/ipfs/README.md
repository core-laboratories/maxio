# Native IPFS integration

The IPFS extension is enabled by default and requires administrator configuration. Set `MAXIO_IPFS_ENABLED=false` to disable it. Start with [architecture](architecture.md), [configuration](configuration.md), and [security](security.md). See [examples](examples.md) for S3 clients. The implementation currently covers public files; the limitations in [architecture](architecture.md) are part of the current release boundary.
