# Security policy

## Reporting a vulnerability

Report a security issue privately through [GitHub Security Advisories](https://github.com/core-laboratories/maxio/security/advisories/new). Include the affected version, reproduction steps, expected impact, and any mitigations you have identified. Do not publish sensitive details in a public issue.

## Updates

Security fixes are released in the latest MaxIO version. Rebuild Docker images to include current base image and package updates.
